===========================================
 IT HELP · SISTEMA DE TICKETS (SPA)
===========================================

Descripción:
Mini aplicación web de tickets con Bootstrap 5.
100% frontend, sin servidor. Persistencia en localStorage.

Estructura:
  /index.html     -> Interfaz principal
  /estilos.css    -> Estilos personalizados
  /app.js         -> Lógica de la aplicación
  /README.txt     -> Este archivo
  /img/           -> Imágenes (opcional)

Funcionalidades:
  [x] Formulario con validación (nombre >=3, email válido, mensaje >=10)
  [x] Prioridad: baja / normal / alta
  [x] Tickets urgentes (alta) resaltados + contador
  [x] Orden: más recientes arriba
  [x] Filtrar por prioridad
  [x] Buscar por texto
  [x] Eliminar ticket
  [x] Marcar como leído / no leído
  [x] Demo control de flujo: switch (clase CSS) + for (contar palabras)
  [x] Persistencia con localStorage

Uso:
  1. Abrir index.html en el navegador.
  2. Llenar el formulario y presionar "Publicar Ticket".
  3. Usar filtros y buscador para localizar tickets.
